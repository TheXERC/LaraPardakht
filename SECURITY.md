# Security Policy

## Supported Versions

This package is actively maintained on the latest stable release line.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by opening a confidential security advisory on GitHub for this repository.

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix (if available)

Do not open public issues for security vulnerabilities.

## Response Process

- We will acknowledge your report as soon as possible.
- We will investigate and validate the issue.
- We will work on a fix and publish a patch release when appropriate.
- We will coordinate disclosure timing with the reporter when possible.
